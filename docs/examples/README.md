# Examples

Tutorials for programmers who embed Texl in their own programs. Each one is a
complete program that you can run.

| Example                                         | Host       | Shows                                                       |
|-------------------------------------------------|------------|-------------------------------------------------------------|
| [A live preview in a web page](web-page.md)     | JavaScript | rendering editor text at a URL, imports, out-of-order results |
| [A report from Python data](python-report.md)   | Python     | globals, a library document, an `async` host function       |
| [Custom loaders](loaders.md)                    | Python     | a scheme of your own, a cache, a loader restricted to one folder |
| [Host functions in Rust](rust-host-functions.md) | Rust      | a built-in that holds Swan functions, an in-memory loader, a leak check |

For a first template, start with [Getting started](../getting-started.md).
